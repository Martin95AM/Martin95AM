# Martin Quest - Game Design Document

## Overview
Martin Quest is a pixel-art adventure RPG inspired by classic top-down worlds. The game blends a personal portfolio experience with a fantasy narrative about discovering the story of Martin through exploration.

## Core Vision
- Create an original world with a strong identity.
- Use a compact color palette and 16x16 tile-based visuals.
- Build the first world as a small village with a clear path and interactions.

## First World: Villa Arias
A small village with:
- Northern forest
- A lake
- A house
- An academy
- A store
- A central plaza
- A southern road

## Player Concept
The player is the protagonist of the story, exploring the village and uncovering Martin's history.

## Technical Goals
- Tile-based world
- Keyboard movement
- Simple scene transitions
- Modular scene and manager structure
